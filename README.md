# CoolWare

CoolWare is a Minecraft Forge 1.8.9 client built from the ScaleHack/Coolware codebase.

## Requirements

- Java 8 JDK
- Minecraft Forge 1.8.9 compatible launcher profile

## Supported Platforms

CoolWare is pure Java and runs on any platform that supports Minecraft Forge 1.8.9:

| OS | Architecture | Status |
|----|-------------|--------|
| Windows | x86_64 | ✅ Fully supported |
| Windows | ARM64 | ✅ Supported (via x64 emulation) |
| macOS | x86_64 (Intel) | ✅ Fully supported |
| macOS | ARM64 (Apple Silicon) | ✅ Supported (via Rosetta 2 or native ARM JDK) |
| Linux | x86_64 | ✅ Fully supported |
| Linux | ARM64 / aarch64 | ✅ Supported (requires ARM64 LWJGL 2 natives in your Minecraft install) |

## Setup

1. Install Java 8.
2. Open the project folder in your editor of choice.
3. Set your `JAVA_HOME` to the Java 8 JDK path.
4. Run a Gradle build:

**Windows:**
```bash
gradlew.bat build
```

**Linux / macOS:**
```bash
chmod +x gradlew
./gradlew build
```

5. Find the built jar in:

```text
build/libs/
```

6. Launch Minecraft 1.8.9 with Forge and place the jar into your mods folder if needed by your workflow.

## Build Notes

- This project uses the older Forge 1.8.9 event and registration system.
- The client loads modules, commands, and mixins through the existing startup flow in `Main`.
- Some features rely on the custom event bus generated by `build.gradle`.
